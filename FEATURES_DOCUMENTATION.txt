PROJECT OVERVIEW
================================================================================
This is a production-grade Kanban board application (similar to Trello) built 
with Next.js. It's designed as a full-stack project management tool with 
comprehensive testing, CI/CD, and maintainable architecture.

Live Demo: https://next-dnd-starter-kit.vercel.app
GitHub: https://github.com/john-data-chen/next-dnd-starter-kit

ARCHITECTURE NOTES
================================================================================

Database Models:
- User: email, name, timestamps
- Board: title, description, owner, members, projects
- Project: title, description, owner, members, board, tasks
- Task: title, description, status, dueDate, assignee, creator, lastModifier

You'll need to add:
- Notification model: type, userId, taskId, boardId, message, read, createdAt
- Tag model (if separate): name, color, boardId
- Activity model (optional): type, userId, entityType, entityId, changes, timestamp

API Routes Currently Available:
- /api/auth/* (authentication)
- /api/boards (board CRUD)
- /api/projects/[id]/permissions
- /api/tasks/[id]/permissions
- /api/users/search

You'll need to add:
- /api/notifications (CRUD)
- /api/notifications/mark-read
- /api/mentions/parse
- /api/tags (if separate)

================================================================================
GETTING STARTED
================================================================================

To use this template:

1. Clone the repository
2. Install dependencies: pnpm install
3. Set up environment variables (see env.example)
4. Start MongoDB: docker-compose up -d (in database folder)
5. Initialize database: pnpm init-db
6. Run development server: pnpm dev

For production:
- Build: pnpm build
- Start: pnpm start
- Test: pnpm test
- E2E: pnpm playwright
